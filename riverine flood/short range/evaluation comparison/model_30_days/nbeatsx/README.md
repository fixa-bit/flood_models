# N-BEATSx 30-day evaluation files

This is the cross-model evaluation copy. Training code, checkpoint, configuration and the full original report are kept in `model/model_30_days/N-BEATSx/`.

- `flood_nonflood_comparison.md`: reusable evaluation-skill output for lead 30.
- `predictions.csv`, `forecasts_quantiles.csv`: forecasts on the held-out dates.
- `scores_by_lead.csv`, `scores_flood_nonflood_by_lead.csv`, `scores_by_season_and_lead.csv`: metric breakdowns.
- `quantile_calibration.csv`, `flood_detection.csv`: interval calibration and flood alerts.
- `verification.json`, `evaluation_manifest.json`: data-integrity and split records.

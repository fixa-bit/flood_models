# Original Marala catchment sources

`global_watersheds/` preserves the [Global Watersheds API](https://mghydro.com/watersheds/help.html) responses and checksum receipts for the published station location (32.67 N, 74.46 E), a nearby-location check, a low-precision comparison and the upstream river network. An additional downstream-flowpath response is retained as inspection evidence. `references/` holds the JICA station-inventory PDF, source methodology pages and licensing evidence.

The original [PMD catchment-area paper](../discharge/pmd/marala_historical_flood_peaks_pmd_journal.pdf) was already saved for discharge work and is referenced in place. Its relevant catchment-area statement is on PDF page 4. The JICA station table is on PDF page 36 and identifies PMD as its source.

The checked [project boundary and review notes](../../../processed/marala/catchment/README.md) are under `processed/marala/catchment/`. Originals remain separate from derived files. These are research delineation sources, not an agency-issued catchment shapefile.

# Marala river-flow projections, 2026–2040

NEX-GDDP-CMIP6, 8 GCMs (ACCESS-CM2, CNRM-CM6-1, EC-Earth3, GFDL-ESM4, MIROC6, MPI-ESM1-2-HR, MRI-ESM2-0, NorESM2-MM), SSP2-4.5 and SSP5-8.5. Values are **ensemble median [min, max] across GCMs** of the change relative to each GCM's own bias-corrected 1986–2014 run. Flows come from the projection-mode TFT (precipitation and temperature only), and event peaks from the storm-rainfall peak model.

**Scenario projections of period statistics. They are not forecasts of particular days or years. Experimental.**

## How large is natural 5-year variability?

Spread of 5-year block statistics inside the bias-corrected **historical** runs (1986–2010 blocks against each GCM's 1986–2014 mean, 40 block × GCM samples). Climate does not change there, so this is the noise floor for one 5-year period of one GCM.

| Statistic | 5–95 % range of block departures |
|---|---|
| Mean flow | -5.6 % to +5.4 % |
| Storm 3-day precipitation | -26.9 % to +32.1 % |
| P(≥400k cusecs) per year | -0.11 to +0.13 |

The ensemble median averages 8 GCMs, which narrows this noise, but changes in storm rainfall and flood probability for single 5-year periods are mostly within it. Use the pooled **2026–2040** row for extremes.

## Limits

- The TFT was fine-tuned on 2016–2023 observations. Inputs outside that climate (for example warmer springs) are extrapolation.
- Daily TFT flows do not contain flash-flood peaks. Event peaks come only from the peak model, which assumes the PMD list is complete for High-class floods (1980–2016).
- Regulation (Indian run-of-river operations, possible new storage, treaty status) is not modelled. Flows are as-if-unregulated upstream of Marala.
- Glacier retreat is not modelled explicitly. The TFT can only represent melt responses seen in 1980–2023.
- For 2026–2040 the forced climate signal is small compared with internal variability, so read the range across GCMs, not a single number.
- Bias correction keeps each GCM's monthly precipitation change but applies it to the ERA5-Land seasonal cycle. ERA5-Land puts about 33 % of the catchment's precipitation in January–March, against 20–23 % in the GCMs, so corrected annual changes differ from the raw GCM annual changes (for example NorESM2-MM, SSP2-4.5: raw −8.9 %, corrected about −1 %).
